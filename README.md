#🏙️Convesion de iconos para commits más comunes en Desarrollo Web

Esta convención sigue los lineamientos de Conventional Commits combinados con Gitmoji, lo que facilita la lectura del historial y la generación automática de changelogs.

| Icono | Tipo de Commit | Descripción |
|:-----:|:--------------:|:------------|
| ✨ | `feat` | Nueva funcionalidad para el usuario |
| 🐛 | `fix` | Corrección de un bug |
| 📝 | `docs` | Cambios en la documentación |
| 💄 | `style` | Cambios de formato/estilo (espacios, comas, punto y coma, etc.) |
| ♻️ | `refactor` | Refactorización del código (sin cambiar funcionalidad) |
| ⚡ | `perf` | Mejoras de rendimiento |
| ✅ | `test` | Añadir o modificar tests |
| 🔧 | `chore` | Tareas de mantenimiento, configuración, dependencias |
| 🚀 | `deploy` | Despliegue a producción/staging |
| 🎨 | `ui` | Cambios en la interfaz o diseño visual |
| 🔒 | `security` | Mejoras o fixes de seguridad |
| 🌐 | `i18n` | Internacionalización y traducciones |
| 📱 | `responsive` | Adaptaciones para móviles/tablets |
| 🗑️ | `remove` | Eliminación de código o archivos obsoletos |
| ⏪ | `revert` | Revertir un commit anterior |
| 🔀 | `merge` | Fusionar ramas |
| 🏗️ | `build` | Cambios en el sistema de build o herramientas |
| 👷 | `ci` | Cambios en integración continua |
| 📦 | `deps` | Actualización de dependencias |
| 🩹 | `hotfix` | Corrección urgente en producción |
| 🚧 | `wip` | Trabajo en progreso |
| 💚 | `ci-fix` | Arreglar el pipeline de CI |
| 🗃️ | `db` | Cambios en base de datos/migraciones |
| 🔍 | `seo` | Mejoras de SEO |
| ♿ | `a11y` | Mejoras de accesibilidad |
